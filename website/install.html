Install Open-Q.

Choose your system. Install the plugin. Open your DAW.

Windows

EXE installer

  1. Choose your build

    Open Settings → System → About. Read System type.

    • x64-based PCx86-64
    • ARM-based PCARM64

    An ARM PC running an x64 DAW needs the x86-64 build.

  2. Run the installer

    Close your DAW and open the downloaded .exe.

    Select VST3, CLAP and/or Standalone. Keep the standard plugin folders.

  3. Open your DAW

    Restart your DAW or rescan plugins, then load Open-Q on a track.

    The standalone app is also available from the Start menu.

Optional: check whether to use the AVX2 build

For Intel/AMD x64 PCs. Both builds have the same EQ features; AVX2 may reduce CPU usage. The standard x86-64 build needs no AVX2 check.

  1. Download Microsoft Coreinfo and extract the ZIP.
  2. In that folder, click File Explorer’s address bar, type powershell, and press Enter.
  3. Paste this block. Accept Microsoft’s licence if prompted.
$required = 'AVX AVX2 BMI1 BMI2 F16C FMA LZCNT MOVBE XSAVE OSXSAVE AES PCLMULDQ CX16 LAHF-SAHF POPCNT SSE3 SSSE3 SSE4.1 SSE4.2'.Split(' ')
$report = & .\Coreinfo64.exe -f 2>&1 | Out-String
$passed = $LASTEXITCODE -eq 0
foreach ($feature in $required) {
    $pattern = '(?m)^[ \t]*' + [regex]::Escape($feature) + '[ \t]+\*'
    if ($report -notmatch $pattern) { $passed = $false }
}
if ($passed) { 'Choose Windows x86-64 AVX2' } else { 'Choose Windows x86-64' }

Result includes AVX2? Download Intel / AMD · AVX2. Otherwise, download Intel / AMD (x86-64). If the check fails, use the main download.

Using an Intel DAW on Apple silicon?
  1. Open Finder → Applications.
  2. Click your DAW’s app once, then press Command + I to open Get Info.
  3. Find the Kind field and use the matching choice below.
  • Application (Intel): download Intel Mac.
  • Application (Apple silicon): download Apple silicon.
  • Application (Universal): look for the Open using Rosetta checkbox. If it is checked, download Intel Mac. If it is unchecked, download Apple silicon.

Optional: check whether to use the AVX2 build

For x86_64 systems. Paste this block into your terminal. It checks every processor listed by your kernel.

awk '
BEGIN {
    n = split("avx avx2 bmi1 bmi2 f16c fma abm movbe xsave aes pclmulqdq cx16 lahf_lm popcnt pni ssse3 sse4_1 sse4_2", required)
    ok = 1
}
/^flags[[:space:]]*:/ {
    seen = 1
    for (i = 1; i <= n; i++)
        if ($0 !~ ("(^|[[:space:]])" required[i] "([[:space:]]|$)")) ok = 0
}
END { print ((seen && ok) ? "Choose Linux x86-64 AVX2" : "Choose Linux x86-64") }
' /proc/cpuinfo

Result includes AVX2? Download Intel / AMD · AVX2. Otherwise, download Intel / AMD (x86-64). Missing information or a failed check means use the main download.

Run the check in the same virtual machine as your DAW, if applicable.

Standalone app won’t launch?

If extraction removed the executable permission, open a terminal in the extracted ZIP folder and run:

chmod +x Standalone/Open-Q

Help & troubleshooting

Windows or macOS shows a security warning

These beta builds are unsigned, and macOS builds are not notarized. Download only from Open-Q’s GitHub Releases.

On macOS, follow Apple’s Privacy & Security instructions for trusted downloaded software.

Verify a download with SHA-256

Replace filename with your downloaded file’s name. Compare the result with SHA256SUMS.txt from the same release.

Windows · PowerShell

Get-FileHash "filename" -Algorithm SHA256

macOS · Terminal

shasum -a 256 "filename"

Linux · Terminal

sha256sum "filename"
Why not choose AVX2 just from the CPU name?

The i3/i5/i7 label alone does not establish compatibility. Open-Q’s AVX2 build requires x86-64-v3 plus AES and carry-less multiplication. The checks above include these extra requirements.

The Linux kernel’s feature list can be incomplete; its check conservatively selects the standard build when information is missing. There is no separate AVX2 download for Mac or ARM64.

Uninstall, roll back or keep presets

Windows: uninstall through Installed Apps. macOS/Linux: delete the copied plugins and standalone app. Your saved user presets remain.

To roll back, close your DAW and reinstall the previous version. Keep a copy of its installer or ZIP.

Early beta versions may change saved-session compatibility. Save your work before testing.
