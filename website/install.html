Downloads

Install Open-Q

Choose the processor architecture matching your DAW. Start with standard x86-64 if you are unsure about AVX2. Preview builds are for testing: save your work and keep the previous installer for rollback.

Downloads are currently unsigned/not notarized and may show operating-system warnings. Download from our GitHub Releases and compare the file's SHA-256 hash with that release's SHA256SUMS.txt. On macOS/Linux use shasum -a 256 filename or sha256sum filename; on Windows use PowerShell Get-FileHash filename -Algorithm SHA256.

Windows

Run the versioned .exe installer. Select VST3, CLAP and/or Standalone, then follow setup. Plugins go into their standard Common Files folders; the standalone app gets a Start-menu shortcut. Use Windows Installed Apps to uninstall.

macOS

Extract the ZIP. Copy the desired bundles to these folders, creating them if needed:

  • VST3: ~/Library/Audio/Plug-Ins/VST3/
  • AU (.component): ~/Library/Audio/Plug-Ins/Components/
  • CLAP: ~/Library/Audio/Plug-Ins/CLAP/
  • Standalone (.app): ~/Applications/ or /Applications/

Finder's Go → Go to Folder accepts these paths. If macOS blocks opening trusted downloaded software, follow Apple's Privacy & Security instructions. There is no macOS installer yet. Delete the copied bundles to uninstall.

Linux

Extract the ZIP. Copy the VST3 bundle into ~/.vst3/ and the CLAP plugin into ~/.clap/, or use the plugin directories configured in your DAW. Launch the executable in the Standalone directory. If extraction removed its executable permission, run chmod +x Standalone/Open-Q. Delete copied files to uninstall.

After installing

Restart your DAW or rescan plugins. Uninstalling binaries does not delete your saved user presets. To roll back, close your DAW and reinstall the previous version. This project is still in development; saved-session compatibility across early versions is not guaranteed.

Report a problem with the full download version, OS, CPU architecture and DAW version.
